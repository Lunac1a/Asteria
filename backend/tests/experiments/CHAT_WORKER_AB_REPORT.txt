收益与限制
实测：复用模型显著减少本负载的 HTTP 延迟，代价是额外约 625 MiB 常驻 Job RSS。
实测：B 的 Post-generation/Persistence 区间约占 HTTP 均值 72%；该区间还包含
生成后编排和 ORM 操作，不能直接认定全部是 PostgreSQL 执行耗时。
推断：真实外部 LLM 耗时加入后，整体百分比收益可能更小；本轮没有测量真实 Provider。
只有单文档、固定短问题、顺序请求及缓存已预热条件；没有并发压力、队列、容量或长期故障实验。
父进程测试埋点/向量哈希的微小开销没有单独消除，两组采用相同方式；嵌套阶段不能相加。
持续 PostgreSQL SQL 日志、Windows↔WSL TCP、系统页缓存均可能影响绝对延迟。
本轮不修改生产代码、Supervisor、数据库配额机制或默认开关，没有 Git 提交。
